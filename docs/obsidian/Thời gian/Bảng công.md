# Quản lý bảng công tháng

Columns: Employee, Regular Hours, Working Days, Paid/Unpaid Leave, Late, Early Leave, OT Normal/Weekend/Holiday, Night Hours, Duty Sessions, Status, Actions. Fixed left `employee`; fixed right `status,actions`.

Actions: view, recalculate, submit review, approve/reject, export. Timesheet chỉ dùng recognized attendance và approved leave/OT/duty.
