# Quản lý điều chỉnh chấm công

Table columns: Request Code, Employee, Date, Request Type, Original Value, Requested Value, Reason, Approver, Status, Actions. Fixed left `requestCode,employee`; fixed right `status,actions`.

Actions: create, view difference, approve, reject, request more information, cancel. Approval tạo adjustment layer và recalculate; không sửa raw log.
