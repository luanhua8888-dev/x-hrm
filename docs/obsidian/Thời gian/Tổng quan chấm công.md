# Theo dõi tổng quan chấm công

Metrics: Total, Present, Absent, Late, Early Leave, On Leave, On Duty, On-call, Night Shift, Missing Check-in/out. Filters: Date, Branch, Department, Employee Type. Click metric mở màn hình chi tiết với filter tương ứng.

API cần: `GET /attendance/dashboard/summary`, `/trends`, `/distribution`, `/operations`. Liên kết [[Thời gian/Chấm công ngày]], [[Thời gian/Ngoại lệ chấm công]], [[Thời gian/Trực và On-call]] và [[Thời gian/Làm thêm giờ]].
