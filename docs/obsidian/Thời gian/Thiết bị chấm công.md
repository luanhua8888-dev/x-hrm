# Quản lý thiết bị chấm công

Columns: Device Name, Code, Type, Branch, Location, IP, Connection Status, Last Sync, Status, Actions. Fixed left `code,name`; fixed right `connectionStatus,actions`.

Actions: view, edit, test connection, sync now, view recent logs, sync history, error logs, deactivate. Raw logs từ thiết bị là immutable.
