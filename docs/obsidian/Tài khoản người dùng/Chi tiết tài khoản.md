# Xem và quản lý tài khoản

Sections: identity, linked employee, roles, effective permissions, data scope, login history và audit history.

Actions: edit, activate/deactivate, lock/unlock, force logout, reset password, revoke sessions. API hiện có `GET/PUT /users/:id`; backend cần action endpoints và audit API.
