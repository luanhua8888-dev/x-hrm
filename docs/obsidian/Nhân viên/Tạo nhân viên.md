# Tạo hồ sơ nhân viên

## Form sections

- Identity: employee code, full name, date of birth, gender, identity number
- Contact: email, phone, address
- Employment: branch, department, job title, manager, hire date, type
- Emergency contact
- Optional user account invitation

API cần: `POST /employees`, catalog Organization và validation employee code/identity uniqueness. Thành công mở [[Nhân viên/Hồ sơ nhân viên]].
