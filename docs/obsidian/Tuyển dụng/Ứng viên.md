# Quản lý ứng viên

Columns: Candidate Code, Full Name, Contact, Current Position, Source, Applications, Last Activity, Talent Pool Status, Actions. Fixed left `code,fullName`; fixed right `actions`. Actions: detail, add application, schedule interview, archive, merge duplicate. API: `/recruitment/candidates`.
