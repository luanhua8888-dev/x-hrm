# Theo dõi hồ sơ ứng tuyển

Columns: Application Code, Candidate, Vacancy, Applied Date, Current Stage, Owner, Score, Next Action, Status, Actions. Fixed left `code,candidate`; fixed right `status,actions`. Actions: move stage, reject, schedule interview, offer, hire. Hire liên kết [[Nhân viên/Tạo nhân viên]].
